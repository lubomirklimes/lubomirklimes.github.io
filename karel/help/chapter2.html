2. Řídicí struktury

Karelův jazyk umožňuje používat cykly (opakování) a podmínky, aby programy byly chytřejší a dokázaly reagovat na situaci ve světě.

2.1 Cykly

OPAKUJ (pevný počet opakování)

Syntaxe vypadá takto:

OPAKUJ 5 {
    KROK
    VLEVO
}
  • Provede 5× blok příkazů uvnitř složených závorek.
  • Každé provedení znamená:
    • KROK (Karel se posune vpřed)
    • VLEVO (Karel se otočí vlevo)

Po skončení cyklu se pokračuje dalším kódem za závorkou.

DOKUD (cyklus s podmínkou)

Další obvyklá forma je tzv. podmíněný cyklus:

DOKUD (VOLNO) {
    KROK
}
  • Znamená: „Dokud je před Karlem volno, dělej KROK."
  • Cyklus končí, když podmínka přestane platit (např. Karel narazí na zeď nebo okraj mřížky).

2.2 Podmínky

Podmínky určují, zda se určitý blok příkazů provede. V Karelovi je často klíčové slovo:

POKUD (VOLNO) {
    KROK
} JINAK {
    VLEVO
}
  • Pokud je před Karlem volné pole (není tam zeď), provede se příkaz KROK.
  • Pokud před Karlem není volno (podmínka je false), provede se blok v JINAK (VLEVO).

Běžné podmínky

  1. VOLNO
    • True, pokud na poli před Karlem není zeď (ani hranice mapy).
  2. ZED
    • True, pokud je před Karlem zeď nebo konec mapy.
  3. ZNACKA
    • True, pokud je na aktuálním poli značka (beeper).

2.3 Ukázkový příklad kombinace cyklu a podmínky

OPAKUJ 3 {
    POKUD (VOLNO) {
    KROK
    } JINAK {
    VLEVO
    }
}
  1. Provede se blok uvnitř složených závorek 3×.
  2. Každé opakování zkontroluje, zda má Karel před sebou volno:
    • Pokud ano → provede KROK.
    • Pokud ne → otočí se vlevo.

Tím se Karel třikrát pokusí pohnout vpřed (pokud to jde), nebo se místo toho otočí.

2.4 Syntaxe bloků

V příkladech výše se používají složené závorky { ... }.
