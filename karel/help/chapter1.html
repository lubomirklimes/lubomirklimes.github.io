1. Základní příkazy

Karel je robot pohybující se na 2D mřížce. Ovládáte ho sadou jednoduchých příkazů.

1 Struktura programu

Každý program začíná klíčovým slovem KAREL a končí klíčovým slovem STOP. Procedury se definují před blokem KAREL … STOP.

// Volitelná definice procedur
PROCEDURA MojeAkce {
    KROK
}

KAREL
    MojeAkce   // volání procedury
    KROK
STOP
💡 KAREL a STOP jsou nepovinné — program lze psát i bez nich. Komentáře začínají //.

2 Pohyb a otáčení

KROK

Posune Karla o jedno pole vpřed (ve směru, kam hledí).

  • Pokud je před ním zeď nebo okraj mřížky → chyba (havárie).
VLEVO

Otočí Karla o 90° doleva.

VPRAVO

Otočí Karla o 90° doprava. Ekvivalent třikrát VLEVO.

STOP

Okamžitě ukončí program. Lze použít kdekoli uvnitř programu.

3 Práce se značkami

Značky (beepery) jsou předměty, které lze pokládat a sbírat. Na jednom poli může ležet více značek.

POLOŽ

Vezme jednu značku z Karlova batohu a položí ji na aktuální pole.

  • Batoh je na začátku neomezený (∞ značek).
  • Pokud je batoh prázdný → chyba.
ZVEDNI

Zvedne jednu značku z aktuálního pole do Karlova batohu.

  • Pokud na poli žádná značka není → chyba.

5 Ukázkový program

// Karel udělá krok, otočí se vpravo, položí značku a zvedne ji
KAREL
    KROK
    VPRAVO
    POLOŽ
    ZVEDNI
    VLEVO
    VLEVO   // otočení o 180°
    KROK
STOP
