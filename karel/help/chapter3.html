3. Definice procedur (podprogramů)

Procedury v Karlovi (někdy nazývané také podprogramy) umožňují seskupit více příkazů do jednoho pojmenovaného celku. Ten pak můžete opakovaně volat. To je užitečné, když se v programu často opakuje stejná série příkazů.

3.1 Základní příklad

PROCEDURA OTOC_SE {
    VLEVO
    VLEVO
}
  • Vytváří proceduru s názvem OTOC_SE.
  • Když se tato procedura zavolá, Karel provede dva příkazy VLEVO a tím se otočí o 180°.

3.2 Volání procedury

Po definici lze proceduru volat jako běžný příkaz:

KROK
OTOC_SE
KROK
  • Karel udělá krok vpřed, zavolá proceduru OTOC_SE (otočí se o 180°) a udělá další krok.

3.3 Struktura definice procedury

Syntaxe definice procedury vypadá takto:

PROCEDURA <jméno> {
    // Blok příkazů
}
  • PROCEDURA je klíčové slovo pro definici.
  • <jméno> je identifikátor procedury (např. OTOC_SE, POZBIREJ_VSE, ...).
  • Blok obsahuje posloupnost příkazů Karla (KROK, VLEVO, POLOZ, atd.).

3.4 Ukázkový delší příklad

PROCEDURA OTOC_SE {
    VLEVO
    VLEVO
}

PROCEDURA OBKROKNI {
    KROK
    VLEVO
    KROK
    VLEVO
}

    OPAKUJ 2 {
    OBKROKNI
    OTOC_SE
  }
  • Definujeme dvě procedury: OTOC_SE a OBKROKNI.
  • V hlavním programu se dvakrát opakuje volání:
    1. OBKROKNI (tj. krok, vlevo, krok, vlevo)
    2. OTOC_SE (otočení o 180°)

Takto se kód stává přehlednějším. Kdyby se tytéž příkazy opakovaly v programu vícekrát, stačí je vepsat do procedury a volat ji podle potřeby.
