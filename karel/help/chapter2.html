2. Řídicí struktury

Cykly a podmínky umožňují Karlovi reagovat na situaci v mřížce.

1 OPAKUJ — pevný počet opakování

OPAKUJ 4 {
    VLEVO   // otočení o 360°
}

Provede blok příkazů přesně n-krát. Počet musí být nezáporné celé číslo.

2 DOKUD — podmíněný cyklus

DOKUD (VOLNO) {
    KROK   // pohyb dokud je před Karlem volno
}

Opakuje blok, dokud je podmínka pravdivá. Podmínka se vyhodnocuje před každým průchodem.

⚠️ Program se automaticky zastaví po 10 000 iteracích, aby se předešlo nekonečné smyčce.

3 POKUD / JINAK — podmínka

POKUD (ZNACKA) {
    ZVEDNI
} JINAK {
    POLOŽ
}

Větev JINAK je nepovinná.

4 Přehled podmínek

Pohyb

PodmínkaPravda, pokud …
VOLNOpřed Karlem je volné pole (není zeď ani okraj)
ZEDpřed Karlem je zeď nebo okraj mřížky
NE_VOLNOekvivalent ZED
NE_ZEDekvivalent VOLNO

Značky

PodmínkaPravda, pokud …
ZNACKAKarel stojí na poli se alespoň jednou značkou
NE_ZNACKAna aktuálním poli není žádná značka
MA_ZNACKYKarel má v batohu alespoň jednu značku
NE_MA_ZNACKYKarlův batoh je prázdný

Domov

PodmínkaPravda, pokud …
DOMAKarel stojí na domovské pozici (domeček 🏠)
NE_DOMAKarel nestojí na domovské pozici

Směr

PodmínkaPravda, pokud …Negace
SEVERKarel hledí na sever (↑)NE_SEVER
JIHKarel hledí na jih (↓)NE_JIH
VYCHODKarel hledí na východ (→)NE_VYCHOD
ZAPADKarel hledí na západ (←)NE_ZAPAD

5 Ukázkové příklady

Pohyb podél zdi

DOKUD (VOLNO) {
    KROK
}
VLEVO   // otočení po naražení

Bezpečný krok

POKUD (VOLNO) {
    KROK
} JINAK {
    VPRAVO
}

Pohyb k domovu

DOKUD (NE_DOMA) {
    POKUD (VOLNO) {
        KROK
    } JINAK {
        VLEVO
    }
}

Sbírání všech značek vpřed

DOKUD (VOLNO) {
    POKUD (ZNACKA) {
        ZVEDNI
    }
