3. Procedury (podprogramy)

Procedury seskupují příkazy do pojmenovaných celků pro přehlednost a znovupoužití.

1 Definice procedury

PROCEDURA OtocVpravo {
    VLEVO
    VLEVO
    VLEVO
}
  • PROCEDURA — klíčové slovo zahajující definici
  • OtocVpravo — jméno (identifikátor); libovolný název bez mezer
  • { … } — tělo procedury (libovolná sada příkazů)
💡 VPRAVO je dnes vestavěný příkaz, takže tuto proceduru není potřeba psát — slouží jen jako ukázka.

2 Volání procedury

KAREL
    KROK
    OtocVpravo   // zavolá proceduru
    KROK
STOP

Proceduru voláte jejím jménem jako běžný příkaz.

3 Pořadí definic a volání

✅
Procedury mohou být definovány kdekoli v programu — před i za blokem KAREL … STOP. Interpret nejprve přečte všechny definice a teprve pak spustí hlavní program.
KAREL
    Pozdrav   // OK – definice je níže, ale funguje to
STOP

PROCEDURA Pozdrav {
    KROK
    VLEVO
}

4 Rekurze

Procedura může volat sama sebe (rekurze):

PROCEDURA JdiDomov {
    POKUD (NE_DOMA) {
        POKUD (VOLNO) {
            KROK
        } JINAK {
            VLEVO
        }
        JdiDomov   // rekurzivní volání
    }
}
⚠️ Program se zastaví po 100 úrovních rekurze, aby se předešlo přetečení zásobníku.

5 Kompletní ukázka

// Procedury definované před hlavním programem

PROCEDURA BezpecnyKrok {
    POKUD (VOLNO) {
        KROK
    }
}

PROCEDURA OtocDokola {
    OPAKUJ 4 {
        VLEVO
    }
}

PROCEDURA SberZnacku {
    POKUD (ZNACKA) {
        ZVEDNI
    }
}

// Hlavní program
KAREL

    // pohyb vpřed, bezpečně
    OPAKUJ 3 {
        BezpecnyKrok
        SberZnacku
    }

    // pohyb k domovu
    DOKUD (NE_DOMA) {
        POKUD (VOLNO) {
            KROK
        } JINAK {
            VPRAVO
        }
    }

    OtocDokola

STOP
